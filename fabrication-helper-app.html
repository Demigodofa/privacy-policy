Daily layout and reference tools.

Fast inputs, shop units, and reference screens for the checks that usually end up on scratch paper.

Fraction Calculator Work in feet, inches, fractions, decimals, and metric conversions.
Pipe Size Lookup Check common nominal pipe sizes, schedules, aliases, and calculated weights.
Structural Shapes Look up included steel, stainless, and aluminum shape rows with source limits.
Linear Cut Planner Plan stock lengths, cuts, order quantities, and drops around saw kerf.
Bolt Circle Layout Calculate hole positions, spacing, angle step, and center-punch lists.
Equal Spacing Lay out holes, tabs, pickets, brackets, and stitch weld centers.

Built to open and work quickly.
